# DemoBlaze Automation Framework
Overview

This project is an end-to-end UI automation framework built using:

- Playwright
- TypeScript
- Page Object Model (POM)

The framework automates the core user workflows available in the DemoBlaze application.

**Application Under Test:**
https://www.demoblaze.com/

- _Technology Stack_
- Playwright
- TypeScript
- Node.js
- GitHub Actions
- Page Object Model Design Pattern

**Implemented Test Scenarios**
**User Registration**
* Open Sign Up Modal
* Enter Username
* Enter Password
* Create User
**User Login**
* Open Login Modal
* Enter Username
* Enter Password
* Verify Successful Login
**Product Listing Validation**
* Navigate to Home Page
* Retrieve Available Products
* Validate Product Count
**Add Product To Cart**
* Select Product
* Add Product To Cart
* Handle Alert Confirmation
**Place Order**
* Add Product To Cart
* Navigate To Cart
* Open Place Order Modal
* Fill Purchase Details
Complete Purchase
Validate Success Message
